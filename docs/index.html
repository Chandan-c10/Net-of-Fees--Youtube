Net of Fees

A personal tool that writes, narrates and renders short videos, then uploads them to its owner’s own YouTube channel.

What it is

A command-line pipeline run by one person for their own channel. It turns a script into a narrated video with captions, and uploads the result. It is not a service, has no users other than its owner, and nothing can be signed up for.

What it does with Google

It uses the YouTube Data API to upload videos to the channel owned by the person running it, after that person has approved each one by hand. It requests the narrowest permission that allows an upload.

Two human approvals

Nothing is written or published automatically. A script must be approved by a person before anything is rendered, and a finished video must be approved by a person before anything is posted. A scheduled run can publish what a human already approved; it can never approve.
